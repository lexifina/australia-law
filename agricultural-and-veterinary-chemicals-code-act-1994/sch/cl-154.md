# 154 Recognition of things done under corresponding laws

(1) In this Code, unless the contrary intention appears, a reference to any thing done by or in relation to the APVMA is a reference to such a thing done under or for the purposes of the Agvet Code of this jurisdiction or of another jurisdiction.

(2) In this Code, unless the contrary intention appears, a reference to any thing done by or in relation to a court is a reference to such a thing done under or for the purposes of the Agvet Code of this jurisdiction or of another jurisdiction.
