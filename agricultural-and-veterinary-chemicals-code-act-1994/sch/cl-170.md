# 170 Provisions relating to offences

(1) Offences against subsections 162(1), (8) and (9) and subsection 163(1) are indictable offences.

(2) All other offences against this Code are summary offences.

(3) A provision of this Code relating to indictable offences or summary offences is taken to refer to bodies corporate as well as to individuals.
