# 33A Execution in so far as proceeding etc. concerns state terrorism

Section 30 does not apply in relation to:

(a) a judgment or order in a proceeding in so far as the proceeding concerns state terrorism; or

(b) an arbitration award in so far as the arbitration concerns state terrorism; or

(c) the arrest, detention or sale of the property in Admiralty proceedings in so far as the proceedings concern state terrorism.
