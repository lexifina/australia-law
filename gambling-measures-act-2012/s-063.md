# 63 Providing non-compliant automatic teller machine

A person contravenes this section if:

(a) the person provides an automatic teller machine on premises; and

(b) the premises are gaming machine premises; and

(c) the automatic teller machine would allow a person to withdraw more than the cash limit.

Civil penalty: 10 penalty units in relation to each day on which the automatic teller machine would allow a person to withdraw more than the cash limit.

Note 1: There is an exception to this section in section 65 (premises covered by exemption and casinos).

Note 2: This section applies whether the person provides an automatic teller machine alone or together with others (see section 8).
