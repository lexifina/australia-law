# 23 Mass adjustment factor

Type 1 vehicles

(1) The mass adjustment factor for a type 1 vehicle is:

(a) for 2025—0.0663; or

(b) for a later year:

(i) if an instrument in force under section 32 determines a number for the mass adjustment factor for type 1 vehicles for the year—that number; or

(ii) otherwise—the mass adjustment factor for type 1 vehicles for the previous year.

Type 2 vehicles

(2) The mass adjustment factor for a type 2 vehicle is:

(a) for 2025—0.0324; or

(b) for a later year:

(i) if an instrument in force under section 32 determines a number for the mass adjustment factor for type 2 vehicles for the year—that number; or

(ii) otherwise—the mass adjustment factor for type 2 vehicles for the previous year.
