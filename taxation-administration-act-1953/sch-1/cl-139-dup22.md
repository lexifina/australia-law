# 139-125 Contents of a release authority

Each release authority issued under section 139-115 must:

(a) be issued to a single *superannuation provider; and

(b) state the amount to be released from each *superannuation interest under the release authority; and

(c) be dated; and

(d) identify that it is a release authority issued following an order under section 139-60; and

(e) contain any other information that the Commissioner considers relevant.
