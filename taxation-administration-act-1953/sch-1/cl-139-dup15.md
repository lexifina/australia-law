# 139-80 When an application is finally determined

Without limiting paragraph 139-60(1)(b) or 139-75(2)(a), an application mentioned in subsection 139-60(2) is finally determined:

(a) when the application is withdrawn; or

(b) if the application is dismissed and an appeal against the decision to dismiss the application is made—when the appeal is withdrawn or determined; or

(c) if the application is dismissed and an appeal against the decision to dismiss the application is not made—when the appeal period in respect of the decision to dismiss the application has ended; or

(d) if an order (other than an interim order) is made as a result of the application—when the appeal period in respect of the order has ended.
