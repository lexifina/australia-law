# 95 Notification of application

(1) If an application has been made to the Registrar under section 92, the Registrar must give a copy of the application in accordance with the regulations.

(2) If the application is in respect of a trade mark already entered on the Register, the Registrar must publish the application in accordance with the regulations.

(3) If the application is in respect of a trade mark whose registration is being sought, the Registrar is to publish the application in accordance with the regulations only if the trade mark is registered.
