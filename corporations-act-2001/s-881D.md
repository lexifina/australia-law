# 881D What happens if an application contains a statement in accordance with paragraph 881B(2)(d)

(1) If a licence application contains a statement in accordance with paragraph 881B(2)(d), ASIC must consider whether ASIC is satisfied that the market will be covered by Division 4.

(2) If ASIC is not so satisfied, the application for the licence must be rejected.

(3) If ASIC is so satisfied, ASIC may (subject to the other provisions about granting licences) grant the licence.

Note: The other provisions about granting licences are in Subdivision A of Division 4 of Part 7.2.
