# 6 Regulations may impose levy

(1) If a costs recoupment determination specifying a default event declaration has been made, the regulations may impose a levy in respect of the refund obligations of registered providers relating to the default event declaration.

(2) For the purposes of subsection (1), the refund obligations of registered providers relating to a default event declaration is the set of obligations that the registered providers would have had, at the start of the day that was 10 days before the day on which the default event declaration was made, to refund accommodation payment balances if it were assumed that at that time the accommodation payment balances became outstanding accommodation payment balances.
